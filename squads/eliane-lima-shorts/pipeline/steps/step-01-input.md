# Step 01: Entrada do Vídeo

## Instrução para o usuário

Para iniciar a produção dos Shorts, o squad precisa do conteúdo do vídeo longo do canal Bellolhar.

**Escolha uma das opções:**

**Opção A — URL do YouTube:**
Cole o link do vídeo do canal Bellolhar. O squad tentará extrair a transcrição automaticamente usando yt-dlp.

Exemplo: `https://www.youtube.com/watch?v=XXXXXXXXX`

**Opção B — Transcrição manual:**
Cole diretamente o texto do vídeo (transcrição, roteiro ou descrição detalhada). Pode incluir timestamps se tiver.

**Opção C — Resumo dos tópicos:**
Descreva os principais tópicos e frases marcantes do vídeo. O squad usará isso como base para sugerir os clips.

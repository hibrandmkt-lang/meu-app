# Step 05: Aprovação dos Roteiros

## Instrução para o usuário

O Roteirista Rápido criou os roteiros completos para cada clip aprovado.

Revise os roteiros em `output/roteiros-shorts.md` e indique:

1. **Aprovar roteiros** — "aprovar roteiro 1, 2 e 3" para seguir para o calendário
2. **Solicitar ajuste** — indique o que mudar (ex: "no roteiro 1, trocar o CTA para falar de agendamento")
3. **Descartar** — se um roteiro não ficou bom, descarte e o squad pode reescrever

Após aprovação, o Publicador Planejado cria o calendário de publicação com checklists para o YouTube Studio.

---

**Dica:** Verifique especialmente o **hook** (primeiras 2 linhas) e o **CTA final** de cada roteiro. São as partes mais importantes para performance.
